# 🚀 Java Concept Explorations

Benvenuti nel mio laboratorio di sviluppo Java. Questo repository raccoglie una serie di moduli indipendenti progettati per esplorare i pilastri della programmazione orientata agli oggetti (OOP) e le best practice del software engineering.

## 📂 Cosa troverai all'interno

Ogni modulo è focalizzato su un aspetto specifico dello sviluppo:

* **[Simple-Banking-Core](./Simple-Banking-Core)**: Gestione di database dinamici e integrità dei dati finanziari.
* **[Smart-Library-Manager](./Smart-Library-Manager)**: Applicazione avanzata del polimorfismo per la logica di business.
* **[Student-Grading-System](./Student-Grading-System)**: Gerarchie di classi e criteri di valutazione differenziati.
* **[Vehicle-Dynamics](./Vehicle-Dynamics-System)**: Dimostrazione di Method Overriding e Runtime Polymorphism.
* **[Java-Collections](./Java-Collections-Basics)**: Dalle basi degli ArrayList alla manipolazione avanzata dei dati.

## 🛠️ Obiettivi del Progetto
L'obiettivo non è solo risolvere esercizi accademici, ma applicare i principi di **Clean Code** e **Modularità** tipici di un ambiente di produzione professionale.
