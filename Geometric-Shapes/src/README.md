# 📐 Geometric Shapes Lab

This module is part of the **Concept-Explorations** project. It focuses on the practical implementation of core **Object-Oriented Programming (OOP)** principles in Java.

## 🧠 Concepts Explored
* **Inheritance**: Used an abstract base class `Shape` to define common properties for all geometric figures.
* **Polymorphism**: Implemented specific behavior for `area()` and `perimeter()` methods in each subclass.
* **Encapsulation**: Leveraged `private` access modifiers and `getters` to ensure data integrity.
* **Input Validation**: Implemented logic within constructors to prevent invalid dimensions (e.g., negative radius or sides).

## 🛠️ Class Structure
* `Shape`: The abstract base class.
* `Circle`: Handles radius-based calculations using `Math.PI`.
* `Square` & `Rectangle`: Handle side and height-based calculations.
* `GeometryWorkshop`: The entry point (Main class) used to test polymorphic behavior through an array of shapes.
