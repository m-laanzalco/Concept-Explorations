# 🛒 Customer Order Service

A scalable e-commerce backend module for managing product inventories and customer billing.

## 🚀 Key Features
* **Object Composition**: Demonstrates professional use of `ArrayList` to manage a collection of `Product` entities within a single `Order`.
* **Automated Invoicing**: Features a robust calculation engine that aggregates product prices into a final grand total.
* **Clean Code Architecture**: High separation of concerns between data models (`Product`) and business processes (`Order`).

## 📊 Technical Flow
The `OrderProcessor` simulates a real-world checkout scenario:
1. Creating a unique Order ID.
2. Dynamically adding items to the cart.
3. Generating a formatted invoice for the end-user.
