# 🐾 Pet Interaction System

A simple demonstration of **Inheritance** and **Class-specific methods** in Java.

## 🧠 What's inside?
* **Pet**: Base class for all domestic animals.
* **Cat**: Shows how to override a parent method (`speak`).
* **Dog**: Shows how to add unique behavior (`fetch`) that only exists in a specific subclass.
* **PetSimulation**: Main entry point to test the animal interactions.
